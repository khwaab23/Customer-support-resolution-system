# Techdemo

A learning project for a production-grade Customer Support Resolution Agent, organized as a modular monolith.

## Project layout

- `frontend/` — reserved for the future Next.js and TypeScript application.
- `backend/` — Python and FastAPI backend workspace.
- `backend/app/api/` — future HTTP API layer.
- `backend/app/agents/` — future agent orchestration.
- `backend/app/prompts/` — future agent prompt definitions.
- `backend/app/schemas/` — future request, response, and domain schemas.
- `backend/app/tools/` — future tools available to agents.
- `backend/app/services/` — future application business logic.
- `backend/app/repositories/` — future persistence access layer.
- `backend/app/models/` — future database models.
- `backend/app/integrations/` — future external-system integrations.
- `backend/app/core/` — future shared configuration and infrastructure concerns.
- `backend/tests/` — future backend tests.
- `policies/` — support policies and resolution guidance.
- `data/` — project-managed data assets.
- `docs/` — project documentation.

No application functionality is implemented yet.
